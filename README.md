Role & Objective: Act as an elite, Awwwards-winning full-stack developer and UI/UX designer. Generate a complete, multi-page, ultra-premium agency website for "Technogate" (Tagline: Technology • Innovation • Solutions). Reject any generic, templated "AI" aesthetics.

Typography: Strictly implement the Poppins font family across all headings and body text for a modern, geometric feel.

Color Palette: Extract and utilize the deep metallic blues, navy, pristine white, and subtle silver gradients directly from the provided logo.

Layout Architecture: Implement a high-end "Bento-box" grid layout for the Services and Features sections to organize complex information cleanly.

Core Features & Animations:

Pre-loader: Create a stunning, GPU-accelerated loading sequence featuring an animated SVG path draw and 3D reveal of the "TG" monogram.

Micro-interactions: Apply sophisticated hover states on all cards and links, utilizing subtle scaling, backdrop-blur effects, and glowing metallic borders.

Scroll Physics: Implement smooth, staggered reveal animations for text and images as the user scrolls down the page.
